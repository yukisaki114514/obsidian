# CHANGELOG

## v0.1.1-preview
- UI 改良：手順を「① 対象 → ② テクスチャ差し替え → ③ 色（任意）→ ④ 生成の設定」の枠に整理。
- 生成ボタンを画面下に固定し、差し替え数・⚠ 数・✕ 数を常時表示（✕ があるときは押せない）。
- 差し替え表に検索欄と「指定済みのみ」フィルターを追加。判定表示を色つきの 1 行に簡略化。
- ツールバーに「このツールについて」「定義を保存／読み込み」を配置。対象レンダラー一覧は初期状態で折りたたみ。
- unitypackage を ShapeFit と同じ tar 構成（フォルダー項目あり）で作成。

## v0.1.0-preview
- 初版。
- 対象指定：アバターモード（配下レンダラーの走査＋除外、複製へ適用）／レンダラーモード（選択レンダラーへ Undo つきで割り当て）。
- 差し替え表：元テクスチャ単位（GUID＋ローカルID 索引）／スロット単位の個別指定。次元タイプ不一致は拒否、解像度・アスペクト比の違いは警告。
- 色プロパティ変更（Color 型プロパティをユーザーが選択する汎用方式）。
- 複製マテリアル生成（EditorUtility.CopySerialized による完全コピー）、同名回避の連番、生成ログ、所要時間表示。
- バリエーション定義 JSON の保存・読み込み。未解決参照を理由つきで一覧表示。
