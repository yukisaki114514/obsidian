Znakisaki ColorVariant v0.1.0-preview
=====================================

衣装・髪などの「色違い」を作る Unity エディター拡張です。
テクスチャを差し替えた複製マテリアルを新規作成し、
アバターの複製（または選択したレンダラー）へ割り当てます。

■ 動作環境
・Unity 2022.3.22f1 / Built-in Render Pipeline
・VRChat SDK は不要です（Renderer と Material のみを扱います）

■ 開き方
メニュー「Znakisaki > ColorVariant > Open Window」

■ 使い方
1. モードを選びます。
   ・アバターモード：アバターのルートを指定します。配下の全レンダラーを走査し、
     生成時にアバターをシーン上に複製して、複製側に割り当てます。元のアバターは変更しません。
   ・レンダラーモード：ヒエラルキーでレンダラーを選び「選択中のレンダラーを追加」を押します。
     生成時はそのレンダラーへ割り当てます（Ctrl+Z で元に戻せます）。
2. 差し替え表で、元テクスチャごとに差し替え先を指定します。
   「スロット単位」表示に切り替えると、スロットごとの個別指定もできます。
   ・✕ 次元タイプ（Texture2D / Cube / 3D など）が違う差し替えは拒否されます。
   ・⚠ 解像度・アスペクト比が違う場合は警告が出ます（生成はできます）。
3. 必要に応じて「色プロパティの変更」で、シェーダーの Color 型プロパティを指定して色を変えます。
   プロパティ名は対象マテリアルのシェーダーから列挙されます。そのプロパティを持たないマテリアルは変更しません。
4. バリエーション名を入力し「色違いを生成」を押します。確認ダイアログで内容を確認してから生成されます。

■ 生成されるもの
・<生成先の親フォルダー>/<バリエーション名>/Materials/<元マテリアル名>_<バリエーション名>.mat
  （初期値：Assets/Znakisaki/ColorVariant/<バリエーション名>/Materials/）
・同名ファイルがある場合は上書きせず、_1, _2 … を付けます。
・同じ元マテリアル・同じ変更内容のスロットは、1 つの複製マテリアルを共有します。
・複製マテリアルは元の完全なコピーで、変わるのは指定したテクスチャ参照と色プロパティだけです
  （Scale/Offset などは変わりません）。

■ 注意
・作成した .mat ファイルの削除は Undo（Ctrl+Z）の対象外です。不要なら生成先フォルダーから手動で削除してください。
・元の .mat アセットと元のアバターは書き換えません。
・シーンは保存しません。必要に応じてご自身で保存してください。
・アバターモードの複製は、Prefab とのリンクが外れた通常の GameObject になります。
・ウィンドウの指定内容はスクリプト再コンパイル時に消えます。残したい場合は定義を保存してください。

■ バリエーション定義（JSON）
「定義を保存…」で差し替え・色の指定を JSON に保存し、「定義を読み込んで表に反映…」で
別アバター・別衣装に同じ指定を再適用できます（読み込みは表を埋めるだけで、生成は別に行います）。
・テクスチャは GUID＋ローカルID で照合します。同じテクスチャを使う別アバターにもそのまま適用できます。
・解決できない項目（アセットの欠落、次元タイプの不一致、対象内に該当スロットがない等）は、
  「未適用・未保存の項目」に理由つきで表示されます。

■ 通信・外部プロセス
行いません。
