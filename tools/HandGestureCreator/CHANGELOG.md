# Changelog

## v1.0.1 (2026-11-18)
- プレビューの保存・復元対象を指ボーンのみに変更（手以外の手作業が巻き戻らない）
- 再コンパイル前・Play モード開始前・Unity 終了時に自動でポーズを復元。復元データをドメインリロード後も保持
- 両手モードに「左右同じ形」切替を追加。OFF で左右別々に編集・.anim 書き出し可能
- 両手モードで「現在の指を読み取る」「.anim から読み込み」「手にフォーカス」が左右両方に対応
- .anim 上書き時に確認ダイアログを追加
- 壊れた JSON の読み込み時にエラーダイアログを表示
- 「全体の曲げ」スライダーの変更が確実にプレビューへ反映されるよう修正
- 製品情報クラス (HandGestureInfo) を追加。ウィンドウタイトルにバージョンを表示
- README に作者・連絡先・導入手順(unitypackage)・仕様と制限を追記

## v1.0.0 (2026-11-18)
- 初回リリース
- 専用ウィンドウ (Tools > Hand Gesture Creator) で指マッスルを編集・ライブプレビュー

- プロジェクト共通ライブラリ (JSON) への保存・読込・削除・検索
- .anim 書き出し / 読み込み、JSON 書き出し / 読み込み
- Humanoid マッスル値ベースによる他アバターへの移植
